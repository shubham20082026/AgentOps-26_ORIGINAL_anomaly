# Design references and attribution

The earthy ReRoute interface combines an original food-crate SVG illustration, warm paper textures, terracotta accents and Georgia serif typography with established open-source UI patterns.

- **Radix Colors**, https://github.com/radix-ui/colors — Sand scale tokens `#63635e`, `#cfceca`, `#21201c` reused as muted text, border and ink tokens. MIT licence; copyright 2021–2022 Modulz, 2022–Present WorkOS. Licence included below.
- **shadcn/ui**, https://github.com/shadcn-ui/ui — design reference for quiet bordered cards, small shadows, consistent spacing and clear label/value hierarchy. No React components or implementation code copied; Streamlit remains the working UI.

No paid templates, external fonts, new frontend dependencies or remote image assets are required. The produce illustration and rescue-progress strip are original code created for this project. Referencing these projects does not imply endorsement.
